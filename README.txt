Character Battle v1.0

起動:
  index.html を開いてください。
  オンライン対戦はインターネット接続が必要です。

公開:
  このフォルダの中身をそのまま GitHub Pages 等へ配置できます。

遊び方:
  1. キャラクターを手入力、またはココフォリアJSONから読み込み。
  2. 「このキャラクターを使用」で確定。
  3. 同じPCで遊ぶか、オンライン部屋を作成。
  4. オンラインではホストがPLAYER 1、参加者がPLAYER 2。
  5. 自分が操作する番のボタンだけ押せます。

注意:
  オンライン通信にはPeerJSの公開クラウドシグナリング/CDNを利用します。
  対戦データはブラウザ間で同期されます。
  ココフォリアのキャラクターJSONは書式の違いにより技能自動検出が外れる場合があるため、
  読み込み後に表示値を確認してください。


v1.1: オフラインP2入力、攻撃ダメージ表示、複数攻撃はダメージ期待値最大を自動選択、組み付き成功で相手の次ターンAP-1。


v1.2: STR追加。組み付きは独立ボタン。命中→通常ダメージ→双方STR判定の成功度対抗。同ランクは防御側勝利、攻撃側勝利時のみ相手の次ターンAP-1。


v1.3: P1/P2キャラクター画像アップロード対応。戦闘中に通常攻撃、強攻撃、組み付き、被弾、回避、防御、観察、回復のCSSアニメーションを追加。
