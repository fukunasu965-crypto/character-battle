Character Battle v1.0

起動:
  index.html を開いてください。
  オンライン対戦はインターネット接続が必要です。

公開:
  このフォルダの中身をそのまま GitHub Pages 等へ配置できます。

遊び方:
  1. キャラクターを手入力、またはココフォリアJSONから読み込み。
  2. 「このキャラクターを使用」で確定。
  3. 同じPCで遊ぶか、オンライン部屋を作成。
  4. オンラインではホストがPLAYER 1、参加者がPLAYER 2。
  5. 自分が操作する番のボタンだけ押せます。

注意:
  オンライン通信にはPeerJSの公開クラウドシグナリング/CDNを利用します。
  対戦データはブラウザ間で同期されます。
  ココフォリアのキャラクターJSONは書式の違いにより技能自動検出が外れる場合があるため、
  読み込み後に表示値を確認してください。


v1.1: オフラインP2入力、攻撃ダメージ表示、複数攻撃はダメージ期待値最大を自動選択、組み付き成功で相手の次ターンAP-1。


v1.2: STR追加。組み付きは独立ボタン。命中→通常ダメージ→双方STR判定の成功度対抗。同ランクは防御側勝利、攻撃側勝利時のみ相手の次ターンAP-1。


v1.3: P1/P2キャラクター画像アップロード対応。戦闘中に通常攻撃、強攻撃、組み付き、被弾、回避、防御、観察、回復のCSSアニメーションを追加。


v1.4: オフラインPLAYER 2にもココフォリアJSON読み込みを追加。組み付き表記（組み付き/組付き/組みつき/組付/グラップル）の検出を強化し、ダメージ記載がなくても組み付き技能を保持。読み込み結果に組み付き検出状況を表示。


v1.5: 提供された実CCFOLIA JSON形式に対応。DBパラメータ（例 +1D4）を読み、1D6+{DB}等を1D6+1D4へ展開。別行のダメージコマンドを技能名で対応付け。組み付きも検出し、ゲーム独自裁定としてダメージ記載なし時は1D6+DB。STR対抗はCoC6能力値に合わせSTR×5判定。


v1.6: STR対抗を抵抗表方式に変更。成功値=50+(攻撃側STR-防御側STR)×5。1D100で成功判定し、成功時のみ次ターンAP-1。戦闘アニメーションを強化し、攻撃/強攻撃/被弾/回避/反撃/受ける/組み付き成功/拘束/脱出/防御/観察/回復のFXを追加。


v1.7: PLAYER 2のココフォリアJSON入力欄をオフライン設定画面に明示的に追加。P2もP1と同じparseCcfを使用。通常攻撃の自動選択を「技能成功率×平均ダメージ」の期待値基準に変更。組み付きは自動選択から除外。


v1.8: JSON解析を再構築。ダメージ行を先に技能名へ正確に紐付け、技能成功率×平均ダメージで通常攻撃を選択。提示JSONでは拳銃80%/1D10を採用。P2設定UIをP1同等のJSON貼付→読み込み→手動確認構成へ再作成。


v1.9: ロビーUIをP1/P2完全対称に再構成。両者に手入力/ココフォリアJSONタブ、画像、確定ボタン、プレビューを配置。P2 JSONハンドラ欠落と戦闘画面P2 portrait要素欠落を修正。オフライン開始は両者をその場で確定してからinitBattleするよう修正。


v1.10: オフライン対戦を停止させていたbattle.jsのreaction()内JavaScript構文エラーを修正。ローカル開始処理にエラー表示も追加。


v1.11: キャラクター確定ボタンが動かない根本原因を修正。classic script間で重複していたトップレベル const $ をmain.js=el、battle.js=belへ分離。全JS構文チェックとmain.js参照DOM ID整合性チェックを実施。


v1.12: 戦闘開始時のDOM不整合を修正。initBattle/renderとHTMLを同期し、欠落していた状態表示・ターン・AP要素を追加。全参照IDと全JS構文を検証済み。


v1.13: 対戦開始時の ReferenceError（inBattle/inBattale未定義）を修正。グローバル戦闘状態 inBattle を定義し、戦闘画面遷移時true、退出時falseへ更新。綴りもinBattleへ統一。


v1.14: main.jsに残存していた未定義$()をel()へ統一。さらにcharacter.jsのclamp()とbattle.jsのclamp宣言がブラウザのclassic scriptグローバルで衝突していたため、battle側をbclampへ変更。これらが初期化を止め、JSON読込・確定ボタンを無反応にしていた原因。


v2.0: 旧runtimeの継ぎ足し修正を停止し、オフライン対戦部分を単一app.jsとして再構築。JSON読込・キャラ確定・画像・対戦開始・通常/強攻撃/組み付き/防御/観察/応急手当/回避/反撃/受けるを同一runtimeで管理。旧network/battle/mainはHTMLから読み込まない。オンラインは安定化後に再実装。


v2.1: オフライン開始不能の原因を修正。v2.0の新しい入力データ形式を、旧character.js用freshCharacter()へ渡していたため戦闘初期化時に例外が発生していた。app.js内fresh()を新形式専用に再実装し、hp/maxHp/skills/state/attacksを戦闘用データへ直接変換するよう変更。


v2.4: PeerJSオンライン対戦を復活。ホストが戦闘計算の正本を持ち、参加者は行動intentを送信、ホストがstateを同期。各プレイヤーは自分のターン/リアクションのみ操作可能。勝者画面はVICTORY、敗者画面はDEFEATを全画面表示。オンライン再戦にも対応。


v2.5: オンライン部屋作成を修正。手動生成IDをPeerコンストラクタへ渡す方式を廃止し、PeerJS Cloudがopen時に発行した実IDをルームコードとして表示。PeerJS未読込・network/server等のエラーも画面に表示。


v2.6: オンラインUI/イベントを一本化。PeerJS公式の new Peer() -> open(id) -> connect/connection フロー。オンライン状態を常時表示。オンライン時は再戦ボタン非表示。
